## Проекты

### [Визуализация алгоритмов задачи коммивояжёра](https://github.com/Sofiro123/tsp-algorithms)

Сравнение четырёх метаэвристик для TSP на Java (муравьиный алгоритм, генетический алгоритм, имитация отжига, гибрид ACO + 2-opt). Веб-интерфейс с картой Leaflet и графиками сходимости.

### [3D-пазл «Утка»](https://github.com/Sofiro123/unity-3d-puzzle)

Мини-игра на Unity 3D: сборка модели утки из отдельных частей, орбитальная камера, перетаскивание деталей и «примагничивание» к целевым позициям.

### Система продажи билетов KinoMania

Прототип клиент-серверного приложения для кинотеатра (Spring Boot, Hibernate, REST, MySQL, Vaadin). Учебная НИР, совместный проект с К. В. Бутовченко. Статья и доклад на конференции «Наука XXI века» (Миасс, 24 апреля 2025).
